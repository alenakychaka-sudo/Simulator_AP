# Лимиты Claude — мини-окно

Маленькое тёмное окно поверх всех окон: сколько израсходовано за сессию (5 ч) и за неделю, и когда сброс. Обновляется раз в минуту.

## Запуск

Нужен Python 3 (на Windows ставится с python.org, tkinter уже внутри) и вход в Claude Code (`claude` → `/login`).

- **Windows:** двойной клик по `limits_widget.pyw` (откроется без консоли)
- **macOS / Linux:** `python3 limits_widget.pyw`

## Управление

- перетащить — зажать мышью в любом месте окна
- клик по «обновлено …» — обновить сейчас
- `×` или `Esc` — закрыть

Цвет полосы: белая — до 70 %, оранжевая — до 90 %, красная — выше.

Токен берётся из входа Claude Code (`~/.claude/.credentials.json`, на macOS — Связка ключей). Если окно пишет «Токен устарел», просто запусти Claude Code — он обновит токен.
